What is NgawourAI?

NgawourAI is a technical project focused on the distribution of lightweight AI models. We specialize in creating models that are small enough to run on consumer hardware without requiring expensive cloud infrastructure.

Crucially, we do not provide inference APIs. Our goal is to empower users to own their AI by providing the model weights and the documentation necessary to run them locally.

Introduction

NgawourAI is dedicated to the distribution of lightweight AI models. We believe that AI intelligence should not be locked behind expensive APIs or proprietary cloud walls.

Our focus is on creating models that are highly capable for specific tasks while remaining small enough to run on resource-constrained hardware, such as Android devices via Termux or low-end laptops.

Core Principle: We provide the weights. You provide the hardware.

LiteAI Philosophy

The LiteAI philosophy rejects the "bigger is always better" paradigm. Instead, we focus on targeted intelligence.

  • Targeted Utility: Designing models for specific tasks rather than generalist mediocrity.
  • Resource Mindfulness: Prioritizing low RAM usage and fast CPU inference.
  • Accessibility: Ensuring models run on hardware available to the average user.

Model Format (GGUF)

All models are released in the GGUF (GPT-Generated Unified Format) format. GGUF is designed for efficient local inference, particularly on CPUs.

Quantization: Q4_K_M

We prioritize Q4_K_M quantization. This reduces the model's precision to 4-bits, which dramatically lowers RAM requirements and increases inference speed while maintaining most of the model's original intelligence.

Running Locally

Once released, models can be run using GGUF-compatible runtimes:

  • llama.cpp: The industry standard for CPU inference.
  • LM Studio: A GUI-based approach for Windows/macOS.
  • Ollama: Simplified local AI management.
bash
./main -m ngawour-model-q4_k_m.gguf -p "Hello!"
